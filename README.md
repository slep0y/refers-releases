# REFERS — файлы обновлений

Здесь лежат только готовые сборки REFERS: установщик, portable-версия, подпись `.sig` и `latest.json` для автообновления.

Исходники — в приватном репозитории; это публичный репозиторий нужен потому, что обновлятор скачивает файлы без авторизации.

Последняя версия: см. Releases.
